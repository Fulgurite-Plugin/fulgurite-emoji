# Emoji

Turns GitHub-style shortcodes into emoji as you type, in [fulgurite](https://github.com/fulgurite-plugin): typing the
closing colon of `:smile:` puts 😄 in the note. The note keeps the emoji itself, so it reads the same everywhere. The
names are GitHub's ([gemoji](https://github.com/wooorm/gemoji)).
